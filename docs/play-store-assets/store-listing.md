# Quill Diary 商店文案

## 應用程式名稱

Quill Diary：本機加密日記

## 簡短說明

寫下生活，也能用 AI 把聊天整理成日記。本機加密保存，支援 Markdown、照片、待辦、人物名冊、彩色標籤、全文搜尋與備份還原；無廣告、無追蹤、免註冊。

## 完整說明

寫下生活，也能聊成日記。

Quill Diary 是以本機加密為核心的 Android 私人日記 App，讓你用文字、照片與對話，留下每天的經歷、心情和重要片段。

想寫就直接記錄；還沒想好怎麼寫，也可以先和你選擇的 AI 聊一聊，再整理成日記。

沒有廣告、沒有行為追蹤，也不需要註冊 Quill Diary 帳號。


【想直接寫，隨時都可以】

無論是簡短的心情筆記，還是完整的生活紀錄，都能依自己的習慣書寫。

• 自訂標題、日期與時間
• Markdown 書寫與預覽
• 加入多張照片與一般檔案附件
• 用彩色標籤整理內容
• 插入待辦清單，追蹤想完成的事

編輯時可以勾選待辦項目；在預覽模式中勾選時，變更會直接儲存至日記。

編輯中的變更會自動儲存為本機加密草稿。有尚未正式儲存的變更時，畫面會顯示「未儲存」提示，提醒你之後繼續完成；確認後再正式儲存至日記庫。


【聊聊今天，再整理成日記】

有些日子發生了很多事，卻不知道從哪裡開始寫。你可以從一句話、一段心情，或一張照片開始，像聊天一樣慢慢分享當天的經歷。

透過 AI 對話梳理事件與感受，再整理成可編輯的日記草稿。生成時，也會將目前這段對話中的照片一併加入草稿。你可以繼續修改，確認並正式儲存後才加入日記庫。

未完成的聊天會列在首頁；日記儲存完成後，也能從該篇日記回顧當時的對話。等待回覆或生成時，可以先離開頁面，稍後再回來查看。

支援 OpenAI、Claude、Gemini、xAI 與自訂連線，服務與模型由你選擇。AI 為選用功能，需自行設定連線，並依服務需求提供 API 金鑰；第三方服務可能另行計費。


【已經寫好的日記，也能重新整理】

想把一篇日記寫得更順、更精簡，或補上當時沒寫清楚的細節，可以使用「日記整理」。

• 語句潤飾：修順用字與表達
• 內容精簡：減少冗詞與重複敘述
• 段落整理：調整內容順序與分段
• 引導補充：透過提問補充事件與感受

可以先討論想調整的方向，再查看原文與修改稿的差異。確認採用後才更新內文，標題、日期、標籤與附件維持原樣。


【用人物、標籤與日曆，找回生活片段】

• 全文搜尋
搜尋日記標題、內文與標籤，找回記得的一句話或某段經歷。

• 日曆回顧
按日期查看日記，回到某一天留下的紀錄。

• 彩色標籤
建立不同顏色的標籤，依生活、工作、旅行、心情等主題分類，選取標籤即可瀏覽相關日記。

• 人物名冊
保存姓名、別名、關係、生日與備註。寫日記時輸入 @，可以快速插入人物名稱，整理與重要人物有關的生活片段。

• 日記總覽
查看全部或指定年份、月份的日記統計，了解標籤使用情形與人物提及概況。

首頁也支援釘選、多選刪除與匯出，方便整理逐漸增加的日記。


【日記與照片，在本機加密保存】

日記內容、照片與附件、人物資料、草稿及搜尋索引都在裝置上加密保存，並支援裝置螢幕鎖與生物辨識解鎖。

建立日記庫時會產生復原金鑰，請另外妥善保存。換機或重新安裝後，需使用備份檔與建立該份備份時的復原金鑰，才能還原日記庫。裝置驗證不能取代還原所需的復原金鑰，開發者也無法代為找回。

使用 AI 時，對話、提示詞與附圖由手機直接傳送到你設定的服務，開發者不提供 AI 中繼伺服器，也不會將日記明文上傳到開發者伺服器。

送出前，可隱藏已登錄的人物姓名與別名，也可自行選取要隱藏的文字，換成代號後再預覽送出內容；原文與對照留在本機。文字隱藏不會遮蔽圖片內容，服務商的資料處理與留存依其政策而定。

API 金鑰保存在裝置安全儲存空間，不包含在日記匯出或完整備份中。


【完整備份與還原】

可在 App 內建立本機備份、匯出備份 ZIP，或手動備份到自己的 Google Drive。Google Drive 提供備份與還原，不是跨裝置即時同步。

完整備份包含正式日記、照片與附件、人物資料、標籤、釘選與 AI 設定。由聊天生成並正式儲存的日記，其保留的聊天紀錄也會納入備份。

一般編輯草稿、未完成聊天、日記整理暫存、API 金鑰與裝置個人化設定不包含在完整備份中。換機或重新安裝前，請先正式儲存重要內容，再建立最新備份，並保留對應的復原金鑰。

備份中的日記與附件維持加密格式，但 ZIP 外層與部分輔助資料未另外加密，請妥善保管備份檔。


【Markdown／HTML 匯入與匯出】

支援將日記匯出為 Markdown 或 HTML，方便在電腦、文字編輯器或其他工具中閱讀、整理與搬移，也能匯入既有的 Markdown／HTML 日記，延續過去的紀錄。

Markdown 與 HTML 匯出為可直接閱讀的明文，請自行妥善保存匯出檔案。


【依自己的習慣記錄】

支援繁體中文與 English，以及淺色、深色與跟隨系統主題。

可調整標題與內文字級、行距及段落間距。直接編輯日記時，新加入的照片可選擇標準、高畫質或原圖品質。


【開源，可供檢視】

Quill Diary 原始碼公開，可供使用者與開發者檢視。

你可以在 App 內自願支持開發者，採單次付款，沒有訂閱，也不影響功能使用。

把每天的想法、心情與值得記住的小事，慢慢留下來。

## 1.3.0 更新資訊

• 新增「聊天日記」：用自己的 AI 服務聊天，再整理成可編輯的加密日記。也可繼續直接寫日記。
• 支援 OpenAI、Claude、Gemini、xAI 與自訂連線。API 金鑰只留在這台裝置，由手機直接連線。
• 可隱藏人物姓名與指定文字，送出前換成代號，原文留在本機。圖片內容不會被遮蔽。
• 回覆與生成可先離開頁面，完成後再回來查看草稿。
• 既有日記可「日記整理」：語句潤飾、內容精簡、段落整理或引導補充，查看差異後才更新內文。
