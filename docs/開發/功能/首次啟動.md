# 首次啟動

這份文件整理 Quill Diary 在「本機還沒有日記庫」時的兩段式體驗：功能介紹 Dialog，以及之後的首次啟動首頁。

只有 `unlocked` 且 `session == null` 才進入首次啟動。安裝介紹只在 `onboarding_intro_seen` 尚未寫入時顯示；看完寫入 `true`，之後不再顯示。已有日記庫不會進入這段流程。

## 什麼時候會出現

| 狀態 | 介紹 Dialog | 首次啟動首頁 |
|------|-------------|--------------|
| 全新安裝，尚無 `recovery.json` | 若尚未看過，會先顯示 | 顯示兩張操作卡 |
| 已看過介紹，但仍未建庫／還原 | 不顯示 | 顯示兩張操作卡 |
| 已有可用 session | 不顯示 | 不顯示，走完整首頁 |
| 鎖定或 `recoveryRequired` | 不顯示 | 不顯示，走原本阻擋畫面 |

完成狀態存在日記庫外的 `app_preferences.json`，key 是 `onboarding_intro_seen`。

## 5 頁功能介紹

Dialog 不可點背景或在第一頁按返回關閉。第二頁起的返回鍵或左右滑動可換頁。最後一頁才出現「開始使用」。內容是條列重點，每頁三點；對話框高度固定在最高的一頁，換頁時不伸縮。強調本機加密、復原金鑰不可找回、AI 只在要求生成或整理時才送到自己設定的服務商，以及備份要手動建立、不會自動同步。日記庫檢查／修復與「支持開發者」不在介紹裡。AI 分身只在第 3 頁人物那點帶過。

五頁主題（摘要，實際標題見 l10n）：

1. 只存在這台裝置的日記
2. 寫日記的方式由你決定（AI 可選，含送出邊界）
3. 用標籤與人物整理回憶（人物那點含 AI 分身）
4. 備份由你決定：完整備份維持加密、手動建立、匯出不加密
5. 復原金鑰：建立時會產生，換裝置、重新安裝或還原都要用

標題列右側可切換中／英文，寫入既有 `app_locale` 偏好。首次啟動的語系判定與保存規則見[個人化設定](個人化設定.md#語言)；首頁首次啟動流程再透過 seed 持久化。

這份介紹不是更新公告。以後若日常操作或隱私邊界改變，才另用一次可略過的說明；它只在已有日記庫、該次發布有明確的使用者可見條目，且這次啟動沒有在顯示安裝介紹時出現。沒有條目就不顯示，也不能單靠 App 版本號。

## 首次啟動首頁

介紹流程完成前，首頁只顯示載入狀態，AppBar 設定入口暫時停用，不渲染可互動的操作卡。流程完成後保留設定入口、隱藏分頁與新增按鈕，並顯示中央兩張卡：

- **建立新的日記庫**：前往設定頁復原金鑰卡片，沿用既有建立金鑰與 `RecoveryKeySaveDialog`
- **轉移既有資料**：前往設定頁，把「本機備份與還原」對齊畫面上方（Google Drive 區塊會接在下方），沿用既有還原流程

設定頁只捲動並聚焦目標卡片，不自動選檔或登入。`recoveryKey` 會聚焦復原金鑰卡片，`externalRestore` 也會在捲動對齊後聚焦本機備份與還原卡片。從設定返回但還沒有可用 session 時，仍停在首次啟動首頁。

尚無復原金鑰時允許登入 Google Drive 並還原，但不能上傳備份。已有日記庫但未解鎖時，維持原本不能改 Drive 帳戶的限制。
