# 首次啟動

這份文件整理 Quill Diary 在「本機還沒有日記庫」時的兩段式體驗：功能介紹 Dialog，以及之後的首次啟動首頁。

只有 `unlocked` 且 `session == null` 才進入首次啟動。介紹另檢查已保存版本是否小於 `onboardingIntroCurrentVersion`；既有日記庫不會因介紹升版而重播。

## 什麼時候會出現

| 狀態 | 介紹 Dialog | 首次啟動首頁 |
|------|-------------|--------------|
| 全新安裝，尚無 `recovery.json` | 若尚未看過目前版本，會先顯示 | 顯示兩張操作卡 |
| 已看過介紹，但仍未建庫／還原 | 不顯示 | 顯示兩張操作卡 |
| 已有可用 session | 不顯示 | 不顯示，走完整首頁 |
| 鎖定或 `recoveryRequired` | 不顯示 | 不顯示，走原本阻擋畫面 |

完成狀態存在 vault 外的 `app_preferences.json`，key 是 `onboarding_intro_version`。

## 5 頁功能介紹

Dialog 不可點背景或在第一頁按返回關閉。第二頁起的返回鍵或左右滑動可換頁。最後一頁才出現「開始使用」。內容是條列重點，不是單一段落；強調本機加密、復原金鑰不可找回，以及 Google Drive 是手動備份、不是自動同步。日記庫檢查／修復與「支持開發者」不在介紹裡。

五頁主題（摘要，實際標題見 l10n）：

1. 私密、安全的日記
2. 寫日記
3. 標籤與人物
4. 復原金鑰請務必保存
5. 備份、還原與匯出

標題下方靠右可切換中／英文，寫入既有 `app_locale` 偏好。若尚未寫過語系且本機仍是空庫，App 層會直接依裝置語系顯示：中文裝置用繁體中文，其餘用英文；首頁首次啟動流程再透過 seed 持久化。已有日記庫、從未設語系的使用者仍維持預設繁中。

## 首次啟動首頁

介紹流程完成前，首頁只顯示載入狀態，AppBar 設定入口暫時停用，不渲染可互動的操作卡。流程完成後保留設定入口、隱藏分頁與新增按鈕，並顯示中央兩張卡：

- **建立新的日記庫**：前往設定頁復原金鑰卡片，沿用既有建立金鑰與 `RecoveryKeySaveDialog`
- **轉移既有資料**：前往設定頁，把「本機備份與還原」對齊畫面上方（Google Drive 區塊會接在下方），沿用既有還原流程

設定頁只捲動並聚焦目標卡片，不自動選檔或登入。`recoveryKey` 會聚焦復原金鑰卡片，`externalRestore` 也會在捲動對齊後聚焦本機備份與還原卡片。從設定返回但還沒有可用 session 時，仍停在首次啟動首頁。

尚無復原金鑰時允許登入 Google Drive 並還原，但不能上傳備份。已有日記庫但未解鎖時，維持原本不能改 Drive 帳號的限制。
