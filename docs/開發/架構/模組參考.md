# 模組參考

這份文件描述目前的模組擁有權與組裝入口。資料流與持久化邊界見[系統架構](系統架構.md)，功能細節見[開發文件導覽](../README.md)。

| 型別／位置 | 職責 |
|---|---|
| [`AiCatalogModel`、`AiThinkingLevel`](../../../lib/domain/ai/ai_catalog.dart) | 官方模型、預設開關與思考能力；設定與各協定欄位轉換在 `ai_connection_settings.dart` |
| `DiaryEntry` | 正式日記內容、標籤、日期與附件順序 |
| [`DiaryEntrySummary`](../../../lib/domain/diary/diary_entry_summary.dart) | 日記列表、搜尋、統計及匯出選擇共用的輕量摘要；不暴露 SQL row |
| [`EditorDraftRecord`、`EditorDraftPendingAttachment`](../../../lib/domain/diary/diary_draft.dart) | 一般與聊天生成草稿的持久化記錄；保持既有 JSON 欄位與 pending 相對路徑 |
| [`EditorDraftSnapshot`](../../../lib/application/editor/editor_draft_snapshot.dart) | 畫面欄位快照、空白與 dirty 判斷、輸入資料轉換 |
| `AssetAttachment`、`PendingAttachment` | 正式附件與尚未提交的附件來源；共置於附件模型 |
| `Person`、`PeopleCatalog`、`PersonDraft` | 正式人物名冊、輸入驗證與關係資料 |
| `PersonMentionStats`、`PersonScopedMentionRank` | 人物提及統計與範圍排行的查詢結果；與人物模型共置 |
| [`TagCatalogItem`](../../../lib/domain/tag/tag.dart) | 標籤文字、強調色與自訂色標記 |
| [`PersonalizationPreferences`](../../../lib/domain/preferences/personalization_preferences.dart) | 語言、主題、鎖定逾時、圖片品質與排版的純值模型；Flutter 顯示轉換另置 |
| [`diary_markdown.dart`](../../../lib/domain/diary/diary_markdown.dart) | Markdown 搜尋文字、摘要與任務項目預覽規則 |
| `VaultId`、`EntryId`、`AssetId`、`DateOnly` | 跨模組識別與日曆日期值 |
| `RecoveryMetadata`、`UnlockedVaultSession` | 復原 metadata、目前解鎖權限與金鑰資料 |

## 日記庫與資料安全

| 元件 | 實作責任 |
|---|---|
| [`VaultRepository`](../../../lib/infrastructure/storage/vault_repository.dart) | 日記庫對外入口：初始化、解鎖、金鑰輪替、正式日記／附件、manifest、索引一致性及複合操作提交順序 |
| [`VaultPeopleService`](../../../lib/infrastructure/storage/vault_people_service.dart) | 人物 CRUD、名冊快取、分析工作、worker、批次補建、進度與取消；由 repository 持有 |
| [`VaultRepairService`](../../../lib/infrastructure/storage/vault_repair_service.dart) | 日記與附件掃描、檢查、修復、隔離、salvage、摘要及重建；由 repository 在修改序列內呼叫 |
| `PeopleStore` | 加解密並驗證正式人物名冊 `vault/people.json.enc` |
| `TagStylesStore`、`PinnedEntriesStore` | 持久化標籤目錄、樣式與釘選；標籤儲存不負責翻譯或 Flutter 色彩轉換 |
| `VaultPathStrategy` | vault、索引、草稿、備份及附件路徑的單一計算入口 |
| `CryptoService`、`DeviceKeyManager` | 文件加解密、Android Keystore 與安全儲存 |
| `AppLockService`、`UnlockModeChangeService` | 解鎖偏好、裝置能力與安全切換解鎖方式 |
| `IndexDatabaseManager`、`IndexDatabase` | 加密索引開關、衍生金鑰、SQL row 解析、查詢與可重建資料 |

修改序列由 repository 擁有；修復與人物實作不經由另一層 repository 包裝呼叫。修復服務只透過明確的 metadata 驗證、manifest 提交與聊天搬移操作協作。取消 UI 操作不略過已開始的磁碟收尾。

## 流程與生命週期

| 元件 | 職責 |
|---|---|
| `AppSessionController` | 解鎖狀態、手動／逾時鎖定、敏感操作及還原後接手 |
| `SessionStartupCoordinator`、`SessionResumeCoordinator` | 啟動、可信裝置失效、背景記錄、驗證時機與待清理資源 |
| `SessionInactivityWatchdog` | 背景逾時與回到前景後的穩定期 |
| [`session_state.dart`](../../../lib/application/session/session_state.dart) | session 狀態、鎖定原因、驗證來源／結果；索引不可讀使用 `SessionFailure` 識別 |
| [`AppLifecycleSessionBridge`](../../../lib/app/app_lifecycle_session_bridge.dart) | 將 App lifecycle 與 pointer 事件接到 session，屬 App shell 整合 |
| `EditorFlowController` | 草稿恢復、正式儲存、刪除及附件操作 |
| `EditorFlowSession` | 每個編輯器獨立的草稿保存佇列與預覽保存版本；離開畫面後完成已擷取快照，停止畫面回呼 |
| `EditorDraftStore` | 加密草稿、pending 附件、預覽材料化與可取消的生成提交 |
| `ChatDiaryController`、`ChatDiaryStore` | 聊天分支、串流、隱私處理、明確生成結果與草稿交接、加密保存及遠端清理 |
| `AiClient`、`AiSettingsStore` | 各 AI 協定、思考參數、加密連線與聊天設定，以及目錄採用後回寫；API Key 只留在裝置安全儲存 |
| `SettingsFlowController` | 設定頁備份／還原／Drive／復原金鑰／檢查與修復的協調 |
| `SettingsPageCapabilities`、`VaultTransferCapabilities` | 純存取條件與明確拒絕原因；不保存翻譯後的字串 |
| `GoogleBillingService`、`SponsorBillingState` | Play 一次性支持與購買狀態；狀態隨實際擁有它的 service 管理 |

## 備份、還原與外部檔案

| 元件 | 職責 |
|---|---|
| [`VaultBackupService`](../../../lib/application/transfer/vault_backup_service.dart) | 本機完整備份、外部交付、Drive 帳號與備份管理 |
| [`VaultRestoreService`](../../../lib/application/restore/vault_restore_service.dart) | 選檔、預檢、備份金鑰驗證、下載及還原前準備 |
| [`PortableTransferService`](../../../lib/application/transfer/portable_transfer_service.dart) | Markdown／HTML 匯出、匯入預覽、確認與交付 |
| `VaultBackupIo` | 完整備份建立、檢查、復原資訊預覽與還原 |
| `PortableExportIo`、`PortableImportIo` | 實際格式處理，直接注入相應的 application 服務 |
| `EasyDiaryBackupImporter` | Easy Diary 備份格式辨識與匯入 |
| `DriveBackupService`、`DriveUploadPlatform` | Drive appDataFolder 與 Android 已啟動上傳工作 |
| `PickedFileMaterializer` | 將本機檔案、content URI 或測試用 bytes 材料化為可讀檔案 |
| `ExternalDirectoryStore`、`ExternalDirectoryPicker` | 最近使用的外部目錄與系統資料夾選擇 |
| `deliverToExternalDirectory`、`AndroidSafFileCopy` | 外部交付與 Android SAF 串流寫入；失敗回傳型別化原因 |

## Provider 與顯示層入口

- [`vault_providers.dart`](../../../lib/application/vault/vault_providers.dart)：日記庫、加密、索引、裝置安全與可攜式 I/O 的組裝點。
- [`vault_backup_providers.dart`](../../../lib/application/transfer/vault_backup_providers.dart)：完整備份與還原服務；打包前把舊 AI 設定搬進日記庫。
- [`ai_connection_providers.dart`](../../../lib/application/ai/ai_connection_providers.dart)：AI 客戶端與加密 AI 設定儲存。
- [`session_providers.dart`](../../../lib/application/session/session_providers.dart)：啟動、執行期 session、有效寫入 session 與索引查詢 session。
- [`diary_entry_providers.dart`](../../../lib/application/diary/diary_entry_providers.dart)：跨功能日記內容、附件、縮圖與 `diaryRevisionProvider`；不依賴編輯器操作。
- [`home_entry_query_providers.dart`](../../../lib/application/home/home_entry_query_providers.dart)：首頁、日曆、釘選與總覽查詢；共同觀察日記 revision。
- [`settings_health.dart`](../../../lib/application/settings/settings_health.dart)：最近維護摘要選擇、異常分組及索引健康規則。
- [`overview_statistics.dart`](../../../lib/application/home/overview_statistics.dart)：總覽統計；畫面文字另由 presentation 格式化。
- [`AppRoutes`](../../../lib/shared/navigation/app_routes.dart)：純路由契約；`AppRouter` 組裝頁面。
- [`portable_transfer_dialogs.dart`](../../../lib/presentation/home/portable_transfer_dialogs.dart)：匯入與 Markdown／HTML 匯出共用篇目選擇及摘要卡片，保留各自的識別值。
- shared presentation 放通用主題、布局、視窗、按鈕與 `AccentChip`；日記預覽、標籤編輯及選擇器放在其功能下。
