# 模組參考

這份文件描述目前的模組擁有權與組裝入口。資料流與持久化邊界見[系統架構](系統架構.md)，功能細節見[開發文件導覽](../README.md)。

## 對話框

置中對話框沿用 [`AppDialogShell`](../../../lib/shared/presentation/widgets/app_dialog_shell.dart)，短確認用 `AppConfirmDialog`。長內容在視窗內捲動，底部的次要工具靠左，取消與主操作靠右，換行時維持對齊。刪除或捨棄使用破壞性確認樣式。

以 HTML 匯出為例，摘要、選項與清單共用 [`AppDialogSummary` 和 `AppDialogSection`](../../../lib/shared/presentation/widgets/app_dialog_section.dart)。需要注意的資訊用 `AppFeedbackBanner`，必須明確同意的操作用 `AppConfirmationCheckbox`。色票和復原金鑰可在內容區保有自己的視覺重點。

## 日記庫與資料安全

| 元件 | 實作責任 |
|---|---|
| [`VaultRepository`](../../../lib/infrastructure/storage/vault_repository.dart) | 日記庫對外入口：初始化、解鎖、金鑰輪替、正式日記／附件、manifest、索引一致性及複合操作提交順序 |
| [`VaultPeopleService`](../../../lib/infrastructure/storage/vault_people_service.dart) | 人物 CRUD、名冊快取、分析工作、worker、批次補建、進度與取消；由 repository 持有 |
| [`VaultRepairService`](../../../lib/infrastructure/storage/vault_repair_service.dart) | 日記與附件掃描、檢查、修復、隔離、salvage、摘要及重建；由 repository 在修改序列內呼叫 |
| `PeopleStore` | 加解密並驗證正式人物名冊 `vault/people.json.enc` |
| [`PersonaStore`](../../../lib/infrastructure/persona/persona_store.dart) | 加解密人物分身 `vault/personas/<person_id>/`；完整備份只輸出重新加密的正式內容，不帶草稿與匯入聊天 |
| `TagCatalogStore`、`PinnedEntriesStore` | 持久化標籤目錄、樣式與釘選；標籤儲存不負責翻譯或 Flutter 色彩轉換 |
| `VaultPathStrategy` | 日記庫、索引、草稿、備份及附件路徑的單一計算入口 |
| `CryptoService`、`DeviceKeyManager` | 檔案加解密、Android Keystore 與安全儲存 |
| `AppLockService`、`UnlockModeChangeService` | 解鎖偏好、裝置能力與安全切換解鎖方式 |
| `IndexDatabaseManager`、`IndexDatabase` | 加密索引開關、衍生金鑰、SQL row 解析、查詢與可重建資料 |

修改序列由 repository 擁有；修復與人物實作不經由另一層 repository 包裝呼叫。修復服務只透過明確的 metadata 驗證、manifest 提交與聊天搬移操作協作。取消 UI 操作不略過已開始的磁碟收尾。

| [`AppLifecycleSessionBridge`](../../../lib/app/app_lifecycle_session_bridge.dart) | 將 App lifecycle 與 pointer 事件接到 session，屬 App shell 整合 |
| `EditorFlowController` | 草稿恢復、正式儲存、刪除及附件操作 |
| `EditorFlowSession` | 每個編輯器獨立的草稿保存佇列與預覽保存版本；離開畫面後完成已擷取快照，停止畫面回呼 |
| `EditorDraftStore` | 加密草稿、pending 附件、預覽材料化與可取消的生成提交 |
| `ChatDiaryController`、`ChatDiaryStore` | 聊天分支、串流、隱私處理、明確生成結果與草稿交接、加密保存及遠端清理 |
| `DiaryOrganizationController`、`DiaryOrganizationStore` | 既有日記的整理對話、候選稿、套用與加密暫存；與聊天草稿分開 |
| [`AiClient`](../../../lib/infrastructure/ai/ai_client.dart)、[`AiSettingsStore`](../../../lib/infrastructure/ai/ai_settings_store.dart) | 各 AI 協定、思考參數、加密連線與聊天設定，以及目錄採用後回寫；API Key 只留在裝置安全儲存 |
| `SettingsFlowController` | 設定頁備份／還原／Drive／復原金鑰／檢查與修復的協調 |
| `SettingsPageCapabilities`、`VaultTransferCapabilities` | 純存取條件與明確拒絕原因；不保存翻譯後的字串 |
| `GoogleBillingService`、`SponsorBillingState` | Play 一次性支持與購買狀態；狀態隨實際擁有它的 service 管理 |

## 備份、還原與外部檔案

| 元件 | 職責 |
|---|---|
| [`VaultBackupService`](../../../lib/application/transfer/vault_backup_service.dart) | 本機完整備份、外部交付、Drive 帳戶與備份管理 |
| [`VaultRestoreService`](../../../lib/application/restore/vault_restore_service.dart) | 選檔、預檢、備份金鑰驗證、下載及還原前準備 |
| [`PortableTransferService`](../../../lib/application/transfer/portable_transfer_service.dart) | Markdown／HTML 匯出、匯入預覽、確認與交付 |
| `VaultBackupIo` | 完整備份建立、檢查、復原資訊預覽與還原 |
| `PortableExportIo`、`PortableImportIo` | 實際格式處理，由 `PortableTransferService` 持有並呼叫 |
| [`EasyDiaryBackupImporter`](../../../lib/infrastructure/storage/import/easy_diary/easy_diary_backup_import.dart) | Easy Diary 備份格式辨識與匯入 |
| `DriveBackupService`、`DriveUploadPlatform` | Drive appDataFolder 與 Android 已啟動上傳工作 |
| `PickedFileMaterializer` | 將本機檔案、content URI 或測試用 bytes 材料化為可讀檔案 |
| `ExternalDirectoryStore`、`ExternalDirectoryPicker` | 最近使用的外部目錄與系統資料夾選擇 |
| `deliverToExternalDirectory`、`AndroidSafFileCopy` | 外部交付與 Android SAF 串流寫入；失敗回傳型別化原因 |

Android 的 `MainActivity` 負責註冊通道與轉交系統結果。裝置金鑰、Drive 登入與 SAF 檔案操作分別由 `DeviceKeyChannel`、`DriveSignInChannel`、`DocumentFileChannels` 管理。原生通知與驗證提示透過 `AndroidAppStrings` 讀取 App 選定的語言。Realm 讀取與欄位對應留在 `EasyDiaryRealmChannel`。

Drive 上傳與取消清理共用 `DriveHttp.kt` 的傳輸與查詢請求，各自決定重試、驗證與清理時機。上傳服務管理 worker 與通知，`DriveUploadJobStore` 管理工作持久化。

Dart 的還原來源各自取得備份，預檢後由設定頁共用確認、金鑰驗證與暫存收尾。`VaultRepairFileOperations` 共用檢查與修復所需的檔案列舉及驗證，修復服務決定何時搬移或刪除。`RecoveryRotationRecord` 負責輪替續跑紀錄的編解碼，提交與回復由日記庫修改序列管理。

`AiTransport` 負責 HTTP 傳輸與端點檢查，`AiClient` 保留各服務商的請求內容與串流解碼。App 語言由 `AppLanguage.flutterLocale` 對應，控制器以 `localizationsFor` 取用訊息，畫面使用 `context.l10n`。AI 提示詞的代號套用屬提示詞模組。

## Provider 與顯示層入口

- [`vault_providers.dart`](../../../lib/application/vault/vault_providers.dart)：日記庫、加密、索引、裝置安全與可攜式 I/O 的組裝點。
- [`vault_backup_providers.dart`](../../../lib/application/transfer/vault_backup_providers.dart)：組裝完整備份與還原服務，接入正式分身的加密備份輸出。
- [`ai_model_thinking_override.dart`](../../../lib/domain/ai/ai_model_thinking_override.dart)：手動模型的不可變 Thinking JSON 對照及請求合併。
- [`ai_model_thinking_dialog.dart`](../../../lib/presentation/ai/ai_model_thinking_dialog.dart)：各檔 Thinking 格式、JSON 驗證與預覽。
- [`ai_connection_providers.dart`](../../../lib/application/ai/ai_connection_providers.dart)：AI 客戶端與加密 AI 設定儲存。
- [`ai_stored_settings.dart`](../../../lib/domain/ai/ai_stored_settings.dart)：連線、AI 功能開關、共用人物隱藏與兩組提示詞覆寫，以及目前設定格式的純 JSON 編解碼。
- [`private_text.dart`](../../../lib/domain/ai/private_text.dart)：聊天與整理共用的文字區間、人物區間。
- [`ai_composer_snapshot.dart`](../../../lib/domain/ai/ai_composer_snapshot.dart)：聊天與整理共用的輸入快照。
- [`ai_prompts.dart`](../../../lib/application/ai/ai_prompts.dart)：聊天與整理的提示詞覆寫解析。
- [`persona_controller.dart`](../../../lib/application/persona/persona_controller.dart)、[`persona_store.dart`](../../../lib/infrastructure/persona/persona_store.dart)：分身材料、生成與加密儲存。聊天室只選用已儲存的內容。
- [`ai_request_preview.dart`](../../../lib/application/ai/ai_request_preview.dart)：兩種聊天室共用的請求預覽。
- [`person_mention_query.dart`](../../../lib/application/people/person_mention_query.dart)、[`person_mention_controller.dart`](../../../lib/application/people/person_mention_controller.dart)：編輯器、聊天與整理共用的 `@` 查詢。
- [`person_mention_text_field.dart`](../../../lib/presentation/people/widgets/person_mention_text_field.dart)、[`person_suggestion_panel.dart`](../../../lib/presentation/people/widgets/person_suggestion_panel.dart)：輸入框與橫向建議列。
- [`session_providers.dart`](../../../lib/application/session/session_providers.dart)：啟動、執行期 session、有效寫入 session 與索引查詢 session。
- [`diary_entry_providers.dart`](../../../lib/application/diary/diary_entry_providers.dart)：跨功能日記內容、附件、縮圖與 `diaryRevisionProvider`；不依賴編輯器操作。
- [`home_entry_query_providers.dart`](../../../lib/application/home/home_entry_query_providers.dart)：首頁、日曆、釘選與總覽查詢；共同觀察日記 revision。
- [`tags_pane.dart`](../../../lib/presentation/home/widgets/tags_pane.dart)：首頁標籤分頁的標籤列表、日記預覽與標籤批次操作。
- [`tag_accent_composer_dialog.dart`](../../../lib/presentation/tag/widgets/tag_accent_composer_dialog.dart)：標籤名稱、顏色與預覽；刪除回呼僅在成功時回傳 `true` 並關閉視窗，取消或失敗保留未存內容。刪除只移除標籤，不刪除日記。
- [`settings_health.dart`](../../../lib/application/settings/settings_health.dart)：最近維護摘要選擇、異常分組及索引健康規則。
- [`overview_statistics.dart`](../../../lib/application/home/overview_statistics.dart)：總覽統計；畫面文字另由 presentation 格式化。
- [`AppRoutes`](../../../lib/shared/navigation/app_routes.dart)：純路由契約；`AppRouter` 組裝頁面。
- [`portable_transfer_dialogs.dart`](../../../lib/presentation/transfer/portable_transfer_dialogs.dart)：匯入與 Markdown／HTML 匯出共用篇目選擇及摘要卡片，保留各自的識別值。
- shared presentation 放通用主題、布局、視窗、按鈕與 `AccentChip`；日記預覽、標籤編輯及選擇器放在其功能下。

- [`app_option_field.dart`](../../../lib/shared/presentation/widgets/app_option_field.dart)：共用欄位選單、鍵盤焦點與停用狀態。
- [`app_menu_style.dart`](../../../lib/shared/presentation/app_menu_style.dart)：協定、Thinking、聊天模型及人物排序的共用選單樣式。

- [`entry_writing_mode_picker.dart`](../../../lib/presentation/home/widgets/entry_writing_mode_picker.dart)：首頁新增日記的響應式選擇器；回傳寫作方式，取消與生命週期中斷不建立內容。
