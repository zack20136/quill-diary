# 本機儲存

這份文件說明檔案放在哪、怎麼保護，以及完整備份帶不帶。演算法細節見[加密格式](../安全/加密格式.md)，備份與還原流程見[備份與還原](../功能/備份與還原.md)。

App 資料根目錄是 `{applicationSupport}/quill_diary/`，由 [`VaultPathStrategy`](../../../lib/infrastructure/storage/vault_path_strategy.dart) 計算。Android `android:allowBackup="false"`，系統自動備份不會另存這些資料。

## `{appSupport}/quill_diary/vault/`

| 路徑 | 內容 | 保護 | 完整備份 |
|------|------|------|----------|
| `recovery.json` | 復原 metadata 與 KDF 描述，不是可直接解檔的密鑰 | 明文 | 包含 |
| `manifest.json.enc` | 日記庫 manifest | LDJ2 | 包含 |
| `people.json.enc` | 人物名冊 | LDJ2 | 有建立人物時包含 |
| `ai_settings.json.enc` | 服務商、模型與思考設定、自訂網址、協定、Workspace ID、自訂提示詞、是否隱藏人物。沒有 API Key 欄位。尚未存過設定時不建立 | LDJ2，與日記同一把復原包裝金鑰 | 檔案存在時包含 |
| `entries/` | 正式日記 `*.md.enc`，以及相鄰的完成聊天 `*.chat.json.enc` | LDJ2 | 包含 |
| `assets/` | 正式附件 | LDJ2 | 包含 |
| `tag_styles.json` | 標籤目錄與樣式 | 明文 | 已保存時包含 |
| `pinned_entries.json` | 釘選日記 ID | 明文 | 已保存時包含 |
| `chat_diary_drafts/` | 未完成聊天、原圖，以及該聊天的生成草稿 | LDJ2 | 排除 |
| `chat_diary_remote_cleanup/` | 服務商暫存檔的清理紀錄，不含 API Key | LDJ2 | 排除 |
| `quarantine/` | 修復時隔離的損壞或衝突內容 | 沿用原檔 | 排除 |
| `*.tmp`、`*.previous` | 寫入中的暫檔與上一份可恢復副本 | 與主檔相同 | 排除 |

LDJ2 檔的檔頭（檔案 ID、vault ID、內容類型、時間）是附加驗證資料，正文才加密。金鑰輪替會重加密 vault 內的 `.enc` 與 `.enc.previous`，因此包含 `ai_settings.json.enc`。修復只掃描 `entries/` 與 `assets/`，不會把 AI 設定當成日記。

升級前的連線與聊天設定若仍留在安全儲存的 `settings`、`chat_diary_settings`，第一次讀取、儲存，或已解鎖時打包，會寫進 `ai_settings.json.enc` 再刪掉那兩筆。檔案已存在時以檔案為準。API Key 不搬移。舊備份沒有這個檔；舊鍵刪除之後再還原這種備份，AI 設定回到預設，金鑰仍留在這台裝置。

## 同目錄的其他檔案

這些路徑與 `vault/` 同層，不進入日記庫 ZIP。

| 路徑 | 內容 | 保護 |
|------|------|------|
| `index/journal_index.sqlite` | 可重建的搜尋、標籤、附件與人物分析索引 | SQLCipher，金鑰由復原包裝金鑰衍生 |
| `drafts/` | 一般編輯草稿與待處理附件 | LDJ2 |
| `backups/*.zip` | 本機完整備份，含修復前備份。外層未加密 | ZIP 外層未加密；成員的保護與 vault 相同 |
| `app_preferences.json` | 語言、主題、自動鎖定、圖片品質、日記排版、首次介紹版本 | 明文 |
| `app_lock_store.json` | 解鎖模式 | 明文 |
| `backup_status.json` | 最近備份狀態 | 明文 |
| `external_directory.json` | 上次選擇的外部資料夾 | 明文 |

## 編輯草稿內部路徑

| 相對 App 資料根目錄 | 內容 |
|------|------|
| `drafts/{draftKey}/draft.json.enc` | 一般編輯草稿 |
| `drafts/{draftKey}/pending/*.enc` | 一般草稿附件 |
| `vault/chat_diary_drafts/<chatId>/editor/draft.json.enc` | 聊天生成草稿 |
| `vault/chat_diary_drafts/<chatId>/editor/pending/*.enc` | 聊天生成附件 |

以上皆為 LDJ2 加密檔，不進入完整備份；草稿保存、還原與清理見[日記編輯器](../功能/日記編輯器.md)。

## Android 上傳暫存

路徑在 `filesDir/quill_diary/`，不是 App support 目錄，也不進入日記庫 ZIP。

| 路徑 | 內容 |
|------|------|
| `drive_upload_jobs/` | 背景上傳工作狀態 |
| `drive_upload_staging/` | 待上傳的完整備份 ZIP |

工作完成、取消或清理後刪除。

## 安全儲存

兩者都不進入 ZIP。

| Namespace | 內容 |
|-----------|------|
| `quill_diary_device` | 可信裝置包裝後的復原金鑰 |
| `quill_diary_ai` | 只留 API Key：`key_openai`、`key_claude`、`key_gemini`、`key_xai`，以及 Custom 的 `connection_key_` 加網址識別 |

## 系統暫存

不進入完整備份。

| 位置 | 內容 | 清理 |
|------|------|------|
| 系統暫存 `quill_diary_draft_preview/` | 草稿解密後的預覽 | 鎖定或還原時清除 |
| 系統暫存目錄中的選檔複本 | 外部備份或可攜式文件材料化後的暫檔 | 該次流程結束後刪除 |
| 系統暫存目錄中的下載 ZIP | Drive 還原下載，以及交付前的備份暫檔 | 該次流程結束後刪除 |

## 完整備份包含與排除

ZIP 名為 `backup_YYYY-MM-DD_HH-MM-SS.zip`（修復前為 `backup_before_repair_...`）。外層不加密，根目錄是 `vault/` 的內容，不含 `vault` 這層目錄名。

包含：`recovery.json`、`manifest.json.enc`、`people.json.enc`、已存在的 `ai_settings.json.enc`、`entries/`、`assets/`、已保存的 `tag_styles.json` 與 `pinned_entries.json`。

排除：`chat_diary_drafts/`、`chat_diary_remote_cleanup/`、`quarantine/`、`.tmp`、`.previous`，以及 vault 以外的索引、草稿、本機 ZIP、偏好、狀態、安全儲存與系統暫存。API Key 不在 ZIP。

明文成員只有 `recovery.json`、`tag_styles.json` 與 `pinned_entries.json`。

Markdown／HTML 只匯出正式日記，不含聊天、人物、AI 設定與 API Key。
