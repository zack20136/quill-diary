# Quill Diary 隱私權政策

**生效日期：2026 年 11 月 10 日**

本政策說明 Quill Diary（Android 套件名稱：`zack20136.com.quill_diary`，以下簡稱「本 App」）如何存取、使用、儲存、傳送及刪除您的資料。專案由 GitHub 帳號 [zack20136](https://github.com/zack20136/quill-diary) 維護；隱私問題與資料處理詢問請使用第 9 節的聯絡管道。

## 快速摘要

- 一般日記功能以本機加密為主，不需建立 Quill Diary 線上帳戶；開發者不會收到您的日記。
- AI 與 Google Drive 為選用功能。AI 內容直接送往您設定的服務，Drive 備份送到您自己的 Google 帳戶。
- 本 App 不內建廣告或行為追蹤 SDK，不出售個人資料，也不把日記明文上傳到開發者伺服器。
- 既有 Drive 工作可能在背景或重開 App 後對帳與清理；App 啟動也會查詢 Google Play Billing 可用性並接手未完成交易，不會自動購買。

## 1. 適用範圍與帳戶

本政策適用於 Quill Diary Android App 的日記、人物名冊、AI 聊天與整理、AI 分身、備份還原、匯入匯出及一次性支持功能。

建立本機日記庫及復原金鑰不是註冊線上帳戶。Google 登入只供選用的 Drive 功能使用，不會建立開發者自有帳戶；本 App 也不能代您刪除 Google 或 AI 服務帳戶。

## 3. 資料外送與第三方服務

開發者不提供 AI 中繼伺服器或日記雲端帳戶系統。除您選用的 AI、Drive、外部檔案交付及相關服務處理外，本 App 不自動把日記內容傳給開發者或其他第三方，也不將資料用於廣告或行銷。

### AI 服務與聊天資料

AI 可使用 OpenAI、Claude、Gemini、xAI 或您指定的 Custom 服務（含 Ollama）。API Key 只用於對應連線與目的地認證；Custom 主機也可能再轉用其他提供商或雲端模型。第三方可能計費，並依帳戶、模型及方案處理與保留輸入、輸出及服務紀錄。

- **聊天與生成日記**：傳送目前選定分支的可用對話、有效提示詞及該功能附圖；切換版本不自動連線。編輯或重試保留舊分支，正式儲存後完成聊天的所有分支納入備份。連線測試只傳測試文字，不使用其他日記。
- **日記整理**：只傳本篇處理後內文、本次選定分支及提示詞，不帶其他日記、原始聊天、圖片或附件。開啟或按「開始整理」只準備本機資料，送出需求或按整理日記才呼叫 AI；確認套用前不修改正式日記。
- **分身建立與更新**：確認材料後才送出。長材料可能先分批提取，再把模型產生的中間證據送往同一服務整合；首次確認無法顯示尚未產生的證據。結果需審閱並儲存才啟用。
- **分身聊天與試聊**：使用目前或候選的人物記憶、聊天風格、固定規則及選定對話，不重新讀取原始日記或匯入聊天。聊天不自動更新分身；刪除日記或取消選取也不會自動移除已整理的記憶。

#### 文字隱藏與圖片

送出前可預覽處理後內容。聊天中手動隱藏只替換實際標記區間，不連帶隱藏其他相同文字；有效提示詞中的對應原文也會替換。開啟人物隱藏時，姓名／別名依各功能的比對或預選標記換成代號；日記整理只隱藏最後確認的區間，分身手動隱藏則使用不可還原的標記。原文、區間及需要的對照留在本機加密保存。

**文字代號不保證匿名，也不遮蔽照片。** App 不自動辨識電話、地址、Email 或所有敏感文字；未隱藏內容、人物關係、地點及照片中的人臉、證件或文字仍可能識別身分。傳送圖片副本會清理姓名、GPS、拍攝資訊等非必要中繼資料，保留方向等顯示必要資訊；影像本身不會遮蔽。

生成日記後，App 在手機還原可還原的代號；目前分支未被模型引用的私密片段仍可能附加為「私密補記」，即使您曾要求模型省略。請在正式儲存前刪除不想保留的內容；還原後原文不自動送回模型。

#### 遠端暫存與服務商留存

內建 OpenAI、Claude、Gemini 可能透過 Files API 暫存圖片，供同段聊天引用；內建 xAI 使用內嵌圖片，不另上傳 Files API。完成或刪除聊天時會嘗試清理；失敗留下加密待清理紀錄，之後進入 AI 功能時重試。未完成聊天仍引用的遠端圖片不清理。

Responses 協定（含 Custom）設定 `store: false`，但不保證零留存。本機刪除、停止回覆、刪除 API Key 或清理遠端圖片，不代表服務商已刪除全部輸入、輸出或紀錄，也不代表不計費。資料使用、模型改進用途、保留期限及刪除方式請確認帳戶與方案政策：[OpenAI](https://developers.openai.com/api/docs/guides/your-data)、[Claude](https://platform.claude.com/docs/en/manage-claude/api-and-data-retention)、[Gemini](https://ai.google.dev/gemini-api/terms)、[xAI](https://docs.x.ai/developers/faq/security)、[Ollama](https://docs.ollama.com/api/authentication)。Gemini 免費與付費服務條款不同；Custom 依所設服務政策。

### Google Drive 與 Google API 資料使用限制

Drive 只要求 `https://www.googleapis.com/auth/drive.appdata`，存取本 App 專用隱藏空間，不要求整個 Drive 讀寫權限。由您手動啟動備份或還原，不是即時／排程同步；先前上傳可在背景完成，對帳、殘檔清理及舊備份輪替可在重開或回前景後自動繼續。

Google 帳戶識別、Email、顯示名稱及授權資訊，只用於可見的帳戶連結、備份還原及收尾，不用於廣告或追蹤，不傳到開發者伺服器或 AI 服務。您另用 Gemini API Key 傳送的內容，依上方 AI 說明處理。

本 App 對 Google API 資訊的使用與傳輸遵守 [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy)，包括 Limited Use 要求。

### Google Play 與外部檔案

Google Play Billing 在 App 啟動時檢查可用性、查詢未完成交易並接續收尾；新購買由您操作並在 Play 介面確認。付款及 Google 持有的交易紀錄依 [Google 隱私權政策](https://policies.google.com/privacy)處理，本 App 不因支持而讀取日記。

完整備份與 Markdown／HTML 匯出交付至您選定的位置。Markdown／HTML 為可直接閱讀的明文；資料夾若由雲端服務提供，後續上傳／同步依該供應商設定，副本由您管理。

## 4. 儲存與安全措施

- 日記正文、附件、人物名冊、編輯與聊天草稿、搜尋索引、AI 設定及分身內容在裝置上加密保存。
- 復原設定及部分輔助資料為明文，例如復原金鑰末 4 碼提示、標籤目錄、釘選 ID、偏好及最近備份狀態。加密檔頭仍可顯示檔案／日記庫識別、內容類型與時間；加密正文不代表所有中繼資料均隱藏。
- 完整備份 ZIP 外層未另加密。日記、附件、人物、AI 設定及正式分身維持加密，但含明文復原資料、存在時的標籤目錄與釘選 ID。還原需用備份當時的復原金鑰，開發者無法代為找回。
- API Key 保存在裝置安全儲存，依連線與目的地取用，不寫入 App 的聊天資料格式、完整備份或日記匯出。
- Google 與內建雲端 AI 使用 HTTPS。Custom 僅允許 loopback、IPv4 私有網段或 IPv6 ULA 使用 HTTP；**此路徑的文字、照片與憑證未加密**，主機名稱、link-local 及公網 HTTP 不允許。App 不略過 TLS 驗證或跟隨 AI 請求重新導向。
- App 支援裝置驗證及背景遮蔽，不阻擋系統截圖。日記生成期間背景自動鎖定暫緩，結束後重新倒數；手動鎖定停止生成，連線中斷或程序重開不自動重送。

本 App 關閉 Android 雲端自動備份，但 Android 12 以上部分廠牌仍可能透過裝置移轉搬移資料。解密預覽、選檔及還原可能在 App 私有暫存產生副本，依對應流程完成或鎖定清理；異常中斷／清理失敗可能使清理延後。請妥善保管裝置、備份及復原金鑰。

## 5. Android 權限與您的選擇

| 權限 | 用途與控制 |
|------|------|
| `android.permission.INTERNET` | AI、Google 登入、Drive、Billing 及既有工作的對帳與清理 |
| `android.permission.ACCESS_NETWORK_STATE` | Drive 上傳判斷連線並重試 |
| `android.permission.USE_BIOMETRIC` | Android 驗證可信裝置解鎖，不讀取生物特徵原始資料 |
| `com.android.vending.BILLING` | 一次性支持、商品及未完成交易查詢 |
| `android.permission.FOREGROUND_SERVICE`、`FOREGROUND_SERVICE_DATA_SYNC` | 完成您手動啟動的 Drive 背景上傳 |
| `android.permission.POST_NOTIFICATIONS` | Android 13+ 上傳前在需要時請求，顯示進度與停止按鈕 |
| `android.permission.WAKE_LOCK` | 上傳期間避免休眠，結束或中斷即釋放 |

拒絕通知仍可啟動上傳；通知抽屜不顯示該通知，系統仍可能顯示前景服務提示。通知／頻道關閉時，可在設定頁 Google Drive 區塊查看進度並停止尚可取消的上傳。

生物辨識視窗確認身分，Google 登入與 Drive scope 是獨立帳戶授權。依賴另加入 `USE_FINGERPRINT` 相容權限及保護內部元件的專屬 signature 權限，不另請求執行時授權；套件查詢也不授予檔案或聯絡人存取權。

本 App 不要求相機、錄音、聯絡人、定位或直接讀取整個媒體庫的權限。圖片與檔案由系統選取器取得，您可取消選取。不使用 AI、不連 Drive、不購買，仍可使用一般本機日記；可在 Android 設定撤銷通知等授權。

## 6. 資料保留、刪除與撤回授權

### 保留期間

| 資料 | 保留與清理方式 |
|------|------|
| 正式日記、人物、附件、分身、AI 設定、偏好與備份狀態 | 主要在裝置保留，直到您刪除、重設對應內容或清除 App 資料；索引可重建，鎖定不刪正式資料 |
| 編輯草稿、未完成聊天及日記整理暫存 | 本機加密保留至正式完成或明確捨棄／刪除，不納入完整備份，重開可接續 |
| 完成聊天 | 正式日記儲存後保留所有分支與一般提示詞快照，納入備份；分身回覆只保存人物／分身識別，不保存分身提示詞全文。聊天不列入一般搜尋、統計或 Markdown／HTML 匯出 |
| 分身更新材料與試聊 | 未完成更新及匯入材料加密保留至儲存或取消；正式儲存後清除材料，失敗重試。試聊關閉／鎖定後清除，不轉為正式聊天 |
| 本機與 Drive 完整備份 | 一般保留目標各為最新 5 份；本機修復前備份共用此數量，清理失敗可能暫留更多。外部副本不自動輪替 |
| Drive 暫檔與工作 | 完成或取消後清理；失敗／中斷可能保留狀態等待對帳、重新授權或清理。最近備份紀錄的帳戶標示可能繼續留在裝置 |
| AI 遠端圖片、請求與紀錄 | 圖片依第 3 節嘗試清理；其他期限與刪除由服務商及方案決定，App 不承諾固定期限或零留存 |

正式分身備份只含已儲存內容，未完成更新與匯入材料排除；分身不在 Markdown／HTML 匯出中。完成聊天只沿用正式日記附件，未收錄或已移除的圖片不另存副本。

### 如何刪除資料

1. **本機內容**：在 App 刪除日記、人物、附件、聊天、草稿或分身；清除 App 資料／解除安裝通常移除沙盒資料。刪除日記會清除相鄰完成聊天，單獨刪除聊天不影響正式日記；刪除分身仍保留既有訊息，須另外刪除聊天。已刪內容也可能仍在舊備份。
2. **備份與匯出**：另行刪除本機備份、Downloads、外部資料夾及其他副本。Drive 備份位於隱藏空間，可在設定選「從 Google Drive 還原」，於「選擇 Google Drive 備份」清單按「刪除備份」；不需執行還原。解除安裝或中斷連線不代表副本已刪除。
3. **Google 授權**：可在 App 中斷 Drive，或依 [Google 帳戶連結管理](https://support.google.com/accounts/answer/13533235?hl=zh-Hant)撤銷存取。中斷／撤銷不等於刪備份，建議先刪備份再中斷；重連需同一帳戶及有效授權。刪除 Google 帳戶須向 Google 辦理。
4. **API Key 與第三方資料**：清空 Key 並儲存可刪對應本機金鑰；確認刪 Custom 連線並儲存，也會移除該連線各目的地的裝置 Key。這不撤銷服務商金鑰、不刪既有聊天或遠端紀錄，請另到服務商撤銷金鑰、刪資料或提出請求。取消設定、改名或只換網址不刪原 Key。

日記整理套用成功、明確刪除整理對話或刪除原日記時，清除本機整理資料；分身材料清理不刪除原始 LINE 文字檔。App 不持有這些外部副本，開發者無法代為刪除裝置、Google 或 AI 帳戶資料；可透過第 9 節詢問操作方式。

### Drive 中止與殘檔

遠端驗證前停止、系統逾時或程序中斷後，App 先對帳：已完成則記錄成功，否則清除殘檔及本機暫存。驗證後中斷，於下次啟動或回前景記錄成功並清理舊備份，不重新上傳；對帳完成前不能新上傳。

清理需授權時可重連原帳戶。確認放棄後，App 盡力刪除已知殘檔並清除本機工作，遠端刪除失敗不阻擋，可能留下 Drive 殘檔，也不記錄成功備份。已送 AI 的內容也不會因取消本機工作而同步刪除。
