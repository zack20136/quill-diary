# Quill Diary 隱私權政策

**生效日期：2026 年 11 月 18 日**

本政策說明 Quill Diary Android App 如何處理、儲存、傳送及刪除您的資料。隱私問題請見[聯絡方式](#聯絡方式)。

## 快速摘要

- 一般日記在裝置上加密保存，無須註冊線上帳戶。開發者無法存取您的本機日記庫。
- 您可選擇使用 AI 或 Google Drive。AI 請求直接送至您設定的服務，Drive 備份則傳到您自己的 Google 帳戶。
- App 未內建廣告或行為追蹤 SDK，開發者不出售您的個人資料，也不接收供 AI 處理的內容或 Drive 備份。

## 裝置上的資料

- App 在裝置上記錄、搜尋與整理您的日記和人物資料。日記、標籤、附件、人物名冊、搜尋索引、草稿、聊天紀錄、AI 設定及分身內容均加密保存。人物名冊可包含姓名、別名、關係、生日與備註。
- 部分輔助資料以明文保存，例如復原金鑰末四碼提示、釘選日記的識別碼、裝置偏好與最近備份狀態。加密檔案的檔頭可能顯示檔案或日記庫識別碼、內容類型及時間。標籤目錄採加密儲存，仍未轉換的舊目錄可能為明文。
- AI API Key 存於裝置的安全儲存空間，按連線與目的地取用。聊天紀錄、完整備份及日記匯出均不包含這些金鑰。
- Android 驗證可信裝置的解鎖身分並保護解鎖金鑰。App 只取得驗證結果。系統截圖及最近使用畫面可能顯示日記內容。背景生成日記期間會暫緩自動鎖定，您可手動鎖定並停止生成。

App 已關閉 Android 系統雲端自動備份，並設定排除 App 資料的裝置移轉規則。Android 12 以上的裝置移轉行為可能因廠牌而異。[Android 系統備份說明](https://developer.android.com/identity/data/autobackup)

## 選用的外部服務

AI、Google Drive 及 Google Play 直接與各自的服務連線。服務方可能取得 IP 位址、請求時間、模型或交易資訊等連線資料，並依自己的政策處理與保留。

### AI 服務與聊天資料

您可使用 OpenAI、Claude、Gemini、xAI 或自訂服務（含 Ollama）。App 將請求和連線所用的 API 認證資訊直接傳往您設定的目的地。自訂主機可能再將資料交給其他服務商或雲端模型。這些服務可能依帳戶、模型或方案計費。

| 功能 | 送出的資料 |
| --- | --- |
| 聊天日記與生成日記 | 目前分支的可用訊息、有效提示詞及該功能選用的圖片。切換分支只切換本機顯示。連線測試使用測試文字。 |
| 日記整理 | 本篇處理後的內文、本次整理對話的選定分支與提示詞。其他日記、原始聊天、圖片和附件留在裝置上。開啟整理及點選「開始整理」會準備本機資料，經您送出需求或要求生成整理稿才會連線，確認套用後才修改正式日記。 |
| 建立或更新 AI 分身 | 您確認選入的日記、匯入聊天中的文字、帶入的現有人物記憶或聊天風格，以及提示詞。App 只傳送處理後的內容。若您確認以原始文字匯入無法辨識的檔案並選入材料，送出的內容可能涵蓋整份文字。長材料可能分批送出，後續也會將模型回傳的中間結果送往同一服務整合。候選內容須審閱並儲存後才生效。 |
| AI 分身聊天與試聊 | 已儲存或候選的人物記憶、聊天風格、固定規則與選定的對話。App 不會為了回覆而重新讀取原始日記或匯入聊天。對話不會自動更新分身，刪除來源日記也不會從已儲存的分身記憶移除相關內容。 |

#### 文字隱藏與圖片

送出前可在支援預覽的流程查看處理後內容。App 會辨識符合規則的電子郵件地址、台灣手機與市話號碼、通過格式及檢查碼驗證的部分身分證字號及信用卡號，以及部分金鑰等憑證。開啟人物隱藏時，也會依各功能的比對規則處理名冊中的姓名與別名。您可手動標記要隱藏的範圍，或針對自動標記的單一位置選擇「取消隱藏」，讓該處以原文送出。需要還原的原文及代號對照留在裝置上加密保存。

文字代號無法保證匿名。地址、銀行帳號、未登錄的姓名及其他未辨識的內容可能原樣送出。傳送用圖片副本會移除 GPS、拍攝時間等非必要中繼資料，保留方向等顯示資訊。照片裡的人臉、證件及文字仍清楚可見。日記、聊天與照片可能含您或他人的敏感資訊，請只選用您有權分享的內容。

生成日記後，App 在裝置上還原模型引用且可還原的代號。若目前分支已送出手動隱藏的私密片段，模型未引用的片段可能另加在「私密補記」，即使曾要求模型省略。儲存前可刪除這些片段。單純由 App 自動辨識而隱藏的內容只在模型引用時還原。App 不會因還原代號而將原文自動送回模型。

#### 遠端圖片與資料留存

內建的 OpenAI、Claude 和 Gemini 可能透過 Files API 暫存圖片供同段聊天引用。內建 xAI 將圖片放在請求中。App 會在完成或刪除聊天後嘗試刪除遠端暫存圖片，並保留未完成聊天仍在引用的圖片。清理失敗時，App 會加密保存待清理紀錄，稍後進入 AI 功能時重試。

使用 Responses 協定時，App 會設定 `store: false`。輸入、輸出及服務紀錄仍可能依服務商、帳戶、模型與方案保留。停止回覆、刪除裝置上的資料或清理遠端暫存圖片，都不會一併刪除服務商保存的所有資料。留存、模型改進用途及刪除方式，以各服務的條款和您採用的方案為準。Gemini 的免費與付費服務適用的資料處理條款不同。[OpenAI](https://developers.openai.com/api/docs/guides/your-data)、[Claude](https://platform.claude.com/docs/en/manage-claude/api-and-data-retention)、[Gemini](https://ai.google.dev/gemini-api/terms)、[xAI](https://docs.x.ai/developers/faq/security)、[Ollama Cloud](https://ollama.com/privacy)

內建的雲端 AI 服務使用 HTTPS。自訂服務只允許使用特定的 IP 位址以 HTTP 連線，包括本機迴路位址、IPv4 私有位址及 IPv6 唯一本地位址。經 HTTP 傳送的文字、照片與憑證未加密。App 會驗證 HTTPS 憑證，AI 請求只送往設定的目的地。

### Google Drive 備份與還原

Google 登入只供選用的 Drive 功能。App 使用 Google 帳戶識別碼、電子郵件、顯示名稱與授權資訊核對帳戶，以及上傳、列出、下載、刪除或清理備份。Drive API 只要求 `https://www.googleapis.com/auth/drive.appdata`，可存取 App 在您帳戶中的專用隱藏空間。裝置會保存備份工作和最近備份狀態，當中可能包含帳戶標示。[Google Drive 應用程式資料空間說明](https://developers.google.com/workspace/drive/api/guides/appdata)

備份與還原由您手動啟動，傳輸使用 HTTPS。上傳可在背景完成，App 也可在重新開啟或回到前景後確認先前上傳是否成功、清理未完成的檔案或輪替舊備份。上傳中止後，App 會先確認雲端是否已有完整備份，再記錄成功或清理未完成的檔案。若需要重新授權，可連結原本的 Google 帳戶繼續處理。放棄清理可解除本機的待處理工作，無法查證或刪除的殘檔可能繼續留在 Drive。

Google 帳戶及 Drive 資料只用於帳戶連結、備份、還原和上述清理工作，不會交給開發者伺服器或 AI 服務，也不會用於廣告或追蹤。您另用 Gemini API Key 傳送的內容依前述 AI 資料處理方式處理。App 使用及傳輸自 Google API 收到的資訊均遵守 Google API Services User Data Policy，包括 Limited Use 要求。[Google API 使用者資料政策](https://developers.google.com/terms/api-services-user-data-policy)

### Google Play 支持

App 啟動時使用 Google Play Billing 檢查可用性、查詢待處理的交易並接續收尾。新的一次性支持付款須由您選擇，並在 Google Play 確認。App 會處理商品、購買狀態及交易識別資訊，不取得信用卡號、不讀取日記，也不建立自有付款資料庫或永久支持紀錄。付款與 Google 端的交易紀錄由 Google Play 處理。[Google 隱私權政策](https://policies.google.com/privacy)

## 匯出、備份與還原

- **匯入與選檔**透過系統選取器讀取您選定的圖片、檔案或資料夾內支援的檔案。檔案供應商可能是其他 App 或雲端服務。選檔、解密預覽與還原可能在 App 私有暫存空間產生副本，並依各流程在作業結束或鎖定時清理。中斷或清理失敗可能延後刪除。
- **Markdown／HTML 匯出**的日記及包含的附件可直接讀取。您另存到系統相簿的圖片也可由裝置上的其他 App 依系統權限存取。選擇在匯出時隱藏人物名稱，只會替換能辨識的姓名與別名。檔案交付後由您管理，若儲存位置由雲端服務提供，後續同步依該服務設定。
- **完整備份**在本機、外部位置與 Google Drive 使用相同的 ZIP 格式。ZIP 外層未加密，日記、附件、人物名冊、完成的聊天、AI 設定、已儲存的分身及新備份的標籤目錄以加密內容納入。復原資料及已儲存的釘選日記識別碼為明文，舊版 ZIP 也可能含明文標籤目錄。未完成的草稿、分身匯入材料、試聊和 API Key 均不隨完整備份移轉。
- **完整還原**成功後，備份中的日記庫會取代目前的日記庫。若目前已在可信裝置解鎖同一日記庫，且備份與目前使用相同一代復原金鑰，App 可沿用目前的解鎖狀態。其他情況須使用備份當時的復原金鑰，開發者無法代為找回。

## 保留與刪除

| 資料 | 保留與刪除方式 |
| --- | --- |
| 本機日記及相關資料 | 日記、人物、附件、AI 設定及分身保留到您刪除、重設對應資料或清除 App 資料。解除安裝通常會移除 App 私有資料。刪除日記會一併清除附屬的完成聊天和整理資料。單獨刪除聊天時仍保留日記。刪除分身後，已有的聊天訊息須另行刪除。 |
| 草稿、聊天與分身材料 | 未完成的編輯、聊天和日記整理會加密保存，供稍後接續，直到完成或明確捨棄。正式儲存日記後，完成的聊天保留各分支和一般提示詞快照。分身回覆保存人物及分身識別，分身提示詞全文不隨訊息保存。聊天不納入一般搜尋、統計或 Markdown／HTML 匯出。分身更新材料在完成或取消更新後清理，試聊在關閉或鎖定時清除。原始匯入檔由您自行管理。 |
| 本機與 Drive 完整備份 | 各以保留最新五份為目標，本機修復前保留的備份也計入。清理失敗可能讓舊備份暫時留存。已刪除的日記仍可能存在於先前建立的備份。您可在 App 刪除本機備份。解除安裝或中斷 Google 帳戶連結後，既有外部備份可能仍在。 |
| Drive 備份與授權 | 在設定的「Google Drive 備份與還原」選擇「從 Google Drive 還原」，於「選擇 Google Drive 備份」清單使用「刪除備份」，即可刪除該份備份，無須還原。可在 App 點選「中斷連結」，或在 Google 帳戶撤銷存取權。撤銷後若要透過 App 刪除備份，須重新授權原帳戶。Google 帳戶本身由 Google 管理。 |
| 外部匯出與相簿副本 | 請從下載項目、相簿、外部資料夾或其他存放處個別刪除。這些副本由您或檔案供應商管理。 |
| API Key 與 AI 服務資料 | 清空對應的 API Key 並儲存即可從裝置移除。確認刪除自訂連線並儲存時，也會移除該連線各目的地的裝置金鑰。只變更名稱或網址時仍保留舊金鑰。已傳給服務商的請求、遠端紀錄、帳戶和金鑰須另向該服務商管理、撤銷或提出刪除請求。 |

Google 帳戶授權可透過 Google 的連結管理頁撤銷。[Google 帳戶連結管理](https://support.google.com/accounts/answer/13533235?hl=zh-Hant)

## Android 權限

| 權限 | 用途 |
| --- | --- |
| `INTERNET` | AI 連線、Google 登入、Drive 與 Play Billing。 |
| `ACCESS_NETWORK_STATE` | 檢查網路狀態，以便重試 Drive 上傳。 |
| `USE_BIOMETRIC` | 透過 Android 完成可信裝置的身分驗證。 |
| `com.android.vending.BILLING` | 查詢一次性支持商品與處理交易。 |
| `FOREGROUND_SERVICE`、`FOREGROUND_SERVICE_DATA_SYNC` | 在背景完成您啟動的 Drive 上傳。 |
| `POST_NOTIFICATIONS` | Android 13 以上會在需要時請求，用於顯示上傳進度與停止按鈕。拒絕或關閉通知後，仍可在設定的 Google Drive 區塊查看進度並停止可取消的上傳，Android 也可能顯示系統服務提示。 |
| `WAKE_LOCK` | 上傳期間防止休眠，結束或中斷時釋放。 |

圖片和檔案透過系統選取器取得。App 不要求相機、錄音、聯絡人、定位或存取整個媒體庫的權限。您可取消選檔或在 Android 設定撤銷通知權限。

## 兒童隱私與政策更新

App 並非專為 13 歲以下兒童設計，也不以蒐集兒童個人資料為目的。如認為兒童資料遭不當處理，請透過下方管道詢問。已傳至第三方的資料依其管理及刪除程序處理。

資料處理方式變更時，會更新此頁及生效日期。若涉及新的 Google 資料存取或用途，App 會事先更新說明並取得必要同意。

Issues 預設公開。您提供的 GitHub 帳號、App 版本與問題情境會用於回覆與處理詢問，內容可能持續公開保留。請勿張貼日記、聊天內容、人物資料、備份、復原金鑰、API Key、交易資訊或 Google 帳戶識別資料。可透過 GitHub 的功能或在原問題提出修改或刪除請求。[GitHub 隱私權聲明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)
